Appearances Library

Pure client-side library for displaying items with different appearances (Banner, List, and more). Supports vanilla JS and React. No API calls — you supply the data.

Vanilla JS

const instance = new Appearance({
  container: document.getElementById('app'),
  items: data,
  topview: {
    name: 'Banner',
    file: 'https://example.com/banner.jpg'  // image, pdf, video, html, or other
  },
  bottomview: {
    name: 'List',
    selectiontype: 'checklist',   // or 'select one'
    style: 'Border',              // or 'shadow'
    fields: 'Name||Description',  // first field = title
    gap: '1%'                     // or '5px', '2%', etc.
  }
});

// Later
instance.update({ items: newData });
instance.destroy();

React

View options

  • name: 'Banner' | 'List' | (more coming)
  • file (Banner): URL or content for image / pdf / video / html / other
  • selectiontype: 'checklist' or 'select one'
  • style: 'Border' or 'shadow'
  • fields: e.g. 'Name||Description||Price' — first is the title
  • gap: CSS gap value ('1%', '5px', '10px', …)

Notes

  • Any view can be used as topview or bottomview.
  • If fields is omitted it defaults to Name.
  • This is the first draft — more views and options will be added.

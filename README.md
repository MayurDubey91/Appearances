# Appearances

A flexible JS library for displaying items (lists, grids, cards, tables, masonry, etc.) with highly customizable appearances.

Supports **vanilla JS** and **React**. Pure client-side — you supply the data, no API calls inside the library.

## Goals
- Multiple view types from the same data
- Full control over item / cell / card appearance
- Lightweight and framework-friendly
- Easy theming and density options

## Status
Early scaffold. Core architecture and API are still being designed.

## Repo structure
```
src/
  core/       # Framework-agnostic logic & types
  vanilla/    # Vanilla JS entry
  react/      # React components
```
